# Табачок — карточки для Telegram-канала

Редактор карточек постов 1280×720 в фирменном стиле канала «Табачок» и генератор текста поста.

## Как запустить
Откройте `index.html` в браузере (двойной клик). Интернет нужен только для шрифта Inter.

Онлайн-версия: https://claude.ai/artifact/Gu4eCiqQjdhDP3Q6eACmzU

## Что умеет
- шаблоны: TRAVA 10 000, CODE 46, Fumo salt
- заголовок, текст или список (строки с «-»), подпись внизу: Поступление / Новинка / Акция / Скидка / Снова в наличии
- фото товара: выбрать, перетащить или вставить из буфера; двигать мышью/пальцем, колесо — размер, наклон, тень
- удаление однотонного фона с фото
- 4 фона: Табак, Ночь, Вишня, Мята
- готовый PNG и копирование картинки в буфер
- текст поста с эмодзи, вкусами, ценой, адресом, хэштегами и пометкой 18+; превью как в Telegram и счётчик лимита подписи (1024 символа)

## Файлы
- `index.html` — редактор (всё в одном файле, логотип встроен)
- `assets/logo.png` — логотип на прозрачном фоне
- `examples/` — исходные карточки-примеры
