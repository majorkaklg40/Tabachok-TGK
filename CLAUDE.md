# Табачок — карточки постов для Telegram

## Как делать пост с товаром
1. Пользователь присылает свои фото товара (часто в руке) и обратную сторону упаковки — оттуда берём характеристики.
2. **Фото для карточки — только из интернета, фото пользователя на карточку НЕ ставим** (они нужны лишь чтобы понять товар, цвет и характеристики). Лучший вариант — официальные PNG производителя уже без фона (пример: www.voopoo.com, картинки на sen.voopoo.com.cn, файлы `uploads/.../<товар>.png` 480×480). Если хост закрыт — добавить его в окружение через update_environment.
3. Вырез должен быть плавным и качественным. Если есть только фото на фоне — `rembg` (`isnet-general-use`) и проверить края крупно; если вырез грязный (как у красного VMATE i3 на красном фоне) — взять другой цвет того же товара, у которого есть чистое фото.
4. Композиция: устройство справа, слегка наклонено (около −12°), с тенью; для набора (устройство + коробка) — только если обе картинки из интернета и чистые.
5. Карточку рендерим через `index.html` скриптом `tools/render-cards.js` (Playwright): заголовок 2 строки, 4 пункта, подпись «Поступление».
6. Текст поста — генератор в `index.html`; в заголовке поста без « · », например `**VOOPOO VMATE i3**`. Цены/вкусы не выдумывать — спрашивать.
7. Сохраняем в `posts/ГГГГ-ММ-ДД/`: `<товар>.png`, `<товар>.txt`, `photos/<товар>.png` (вырезка), коммит в `main`.
8. **К каждому запросу — артефакт-редактор.** Для каждого набора постов создать `posts/ГГГГ-ММ-ДД/batch.json` (вкладки = посты; картинка, все поля карточки, положение/размер/наклон товара, готовый текст), собрать страницу `python3 tools/make_batch.py posts/<дата>/batch.json <scratchpad>/posts-<дата>.html` и опубликовать через Artifact (новый URL на каждый запрос). Ссылку записать в таблицу ниже.
